# 超市策略 v2.0(中期版, 单一权威)

> 2026-09-17 数据驱动重大修正: **废弃 v1.0 的"薄利快周转/卖出不亏就是赚"**。
> 实证依据: v1.0 规则运行 15 笔(paper+实盘) → 胜率 67% 却**净亏 $0.44**,
> 因为平均盈利 +0.73% / 平均亏损 -1.69%(盈亏比 0.43, 保本需 70% 胜率)。
> 根因: **紧止盈(浮盈0.5%就走)+ 宽止损(2~15%)** = 负期望组合。
> 本版把止盈、止损、持有期一次性对齐到"中期"。

## 定位

Bitget 美股永续(20x, $2/批, 全仓)上开一个**中期**超市:
**顺势低吸进货 → 持有数日~数周 → 趋势破坏或达标才出货**。
利润来源是**盈亏比(≥2:1)**, 不是高胜率(实证 40~45% 胜率 + 2:1 即为正期望)。
AI 是唯一决策者(选品/定价/清仓), 程序只做四道门与风控。

## 进货(五道门, 全过才买)

1. **方向门**: 已收日线 trend_up(ADX≥25)才做多 / trend_down(ADX≥25)才做空;
   例外=深跌企稳票(跌≥40%+企稳)。周线明确反向降权。
2. **位置门**: 回踩 MA10/VWAP/前高企稳才买; 距 20 日高 -1~-5% **且近5日创过新高**(趋势仍在推进)
   为最优进货区(实证 53722 样本: 有新高超额 +0.45%, 无新高仅 +0.10%); 距高 > -1%(贴顶)不买。
3. **结构门**: 止损位清晰(结构位外侧 **3%~15%**), **RR≥2.0**, 无止损价=拒单。
4. **天气门**: SPY 日线 trend_down(ADX≥25) → **禁开多仓**(程序级; 空单/深跌反转例外);
   SPY 24h 跌幅 >3% → 当日禁开新仓。
5. **实证门(负面清单)**: RS(vs SPY 20日) < -10% → 拒(fwd5 胜率仅 13.6%);
   距 20 日高 ≤ -10% 且日线非 trend_up → 拒(fwd5 胜率仅 16.0%)。

## 出货(中期规则: 趋势破坏 或 达标, 不因小额浮盈清仓)

- **浮盈 <4% 且日线/结构未坏 → 继续持有**(禁止因 0.5~2% 浮盈清仓 —— 这是 v1.0 的亏损来源)
- 浮盈 4%~8% → 达中期目标, 可兑现; 日线仍强(放量上攻)可持有博 10~12%
- 结构破坏(放量跌破 MA30/前低/结构位, 或已收日线转 trend_down)→ 立即 CLOSE
- 正常回调(浮盈回吐 1~3%)→ **不动手**(中期持仓必须承受的波动)
- 持仓 ≥14 天未达止盈 → 清仓让位评估(资金占用+资金费率)

## 库存(套住怎么拿)

- 结构未坏(未跌破止损位/关键均线)+ 亏 <8% → 拿住等回涨(容忍 10-15% 深回调)
- 亏 ≥10% → 必须认真评估; ≥15% → 失控, 立即离场
- 已收日线转坏 / 跌破结构位 → 立即认错(不等盈亏线)
- 补货(加仓): 浮亏禁摊平, 浮盈才补; 批次 ≤3

## 风控(硬约束, 代码即法律)

| 项 | 值 |
|---|---|
| 名义总额 | ≤ 净值×6 |
| 多头不同标的 / 空头 | 6 / 2 |
| 单标的批次 | 3($6 保证金) |
| 止损距离 | **3%~15%**(下限 3% 避免被正常回调打掉) |
| 盈亏比 | **≥2.0**(临界 1.0~2.0 自动修正 TP) |
| 当日亏损熔断 | **净值 5%**(原 30% 过宽) |
| 连亏熔断 | 3 次停 2h |
| 交易所侧 | 每仓必挂 TPSL(开仓后立即挂, 失败即平仓回滚) |

## 运行节奏

- 30 分钟一轮; 每轮 15 标的(持仓≤6 + 热门前2 + 异动前3 + 轮转补齐)
- 有效候选池 = 成交额≥$30万或热门(实测 79 只; 9 轮覆盖全池)
- 周末停机(TPSL 兜底); 每日 09:00 体检推送 Telegram

## 数据口径(全部经实证校准)

- **方向权威=已收盘日线**(剔除进行中的最后一根, 防盘中抖动致误判)
- 量比/盘口买卖压/ADX 高低 = **无预测力, 禁止作为买入理由**(可作辅助事实)
- 有效进货证据(2026-09 大规模复核后的修正值): RSI 40-55、乖离 MA30 ±5%、距高 -1~-5% **且近5日创新高**
  (超额 +0.45% vs 无新高 +0.10%)、RS(个股 vs SPY, <-10% 为禁区)
- **修正记录**: 早期"距高 -1~-5% 胜率 60-62%"与"MACD 近零轴 67%"来自小样本, 53722 样本复核后
  前者修正为 52%(胜率)/+0.31%(超额), 后者(MACD)**不成立**(不构成有效区分)
- 情绪评分 0-100(池内宽度 35% + 中位涨幅 + 极端分布 + VIX 30%), 作为事实输入
- 大盘: SPY/QQQ 24h + 已收日线 regime; 天气门与大盘门控用它
