# 超市策略 v1.0(最终版, 单一权威)

> 用户 2026-09-11/12 全部反馈总结 + 研究数据定稿。一切代码/提示词以此为准。
> 这是"唯一答案"——不再留模糊空间给 AI 自行发挥或后续反复调参。

## 定位

Bitget 美股永续(20x, $2/批, 全仓)上开一个 AI 经营的超市:
**薄利快周转 = 利润来源;拿住结构未坏的货 = 库存策略;坏天气不开门 = 整体防御。**
AI 是唯一决策者(选品/定价/清仓),程序只做四道门与风控。

## 进货(四道门, 全过才买)

1. **方向门**: 日线向上(ADX≥25)才做多 / 日线向下(ADX≥25)才做空;
   唯一例外=深跌企稳票(跌≥40%且站上MA5+反弹≈5%的热门票, 可低吸尝试)。
   周线明确向下的票降权(季节视角: 不逆季度大势)。
2. **位置门**: 回踩 MA10/VWAP/前高企稳(缩量)才买;乖离 MA30 > +5% 视为追高, 不买。
3. **结构门**: 止损位必须清晰(结构位外侧 2%~15%), RR≥1.5, 无止损价=拒单。
4. **天气门**: SPY 24h 跌幅 >3% = 当日禁开新仓(系统性雨天); 已有库存照常管理。

## 出货(任一满足就卖, 卖出不亏就是赚)

- 浮盈 ≥0.5% 且动能减弱(滞涨/长上影/盘口卖压/缩量)
- 浮盈 ≥1% 且盘口买卖比 ≤0.8(卖压明显)
- TP 触发(正常 2~4%, 强趋势/深跌反转可 5~8%, >8% 不给)
- 持仓 ≥7 天未达止盈 → 到期清仓评估(资金占用+费率=仓库租金)

## 库存(套住怎么拿)

- 日线未坏 + 没买在高位(乖离≤5%时买入)+ 亏<8% → 拿住等回涨
- 亏≥10% → 必须认真评估; 亏≥15% → 失控, 立即离场
- 日线明确转坏/跌破结构位 → 立即认错(不等盈亏线)
- 补货(加仓): 浮亏 >5% 且未企稳 → 禁止; 批次≤3

## 风控(硬约束, 代码即法律)

| 项 | 值 |
|---|---|
| 名义总额 | ≤ 净值×6(爆仓线≈整体-16.7%) |
| 多头不同标的 / 空头 | 6 / 2 |
| 单标的批次 | 3($6保证金) |
| 止损距离 | 2%~15% |
| 盈亏比 | ≥1.5(临界自动修正TP) |
| 日亏熔断 / 连亏 | 30% / 3次停2h |
| 交易所侧 | 每仓必挂TPSL, 先挂后开 |

## 运行节奏

- 30 分钟一轮, 每轮15标的(持仓+热门3+异动3+轮转); 周末停机(TPSL兜底)
- 亏损单的"等回涨"以日线为裁判, 不以时间为裁判(7天为上限审计)
