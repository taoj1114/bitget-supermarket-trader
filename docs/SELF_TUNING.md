# AI 自迭代系统(Self-Tuning)

> 目标:让系统**自己看懂自己的成交记录**,找出亏损规律并调整自己 —— 而人类只提供护栏。

## 闭环

```
决策留痕(带特征)  →  每日复盘统计  →  AI 提案  →  程序护栏校验  →  应用(规则区/参数)
      ↑                                                                      ↓
      └────────────  观察 ≥10 笔  ←  通知  ←  版本快照(可回滚)  ←───────────┘
```

1. **决策留痕**:每次开仓把决策时的特征(`反转类型 / 周期桶 / 1H结构 / 动量 / 杠杆 / 保证金`)写进账本,
   与最终盈亏绑定 —— 这是自我审视的**证据基础**。
2. **每日复盘**(`supermarket-selftune.timer`,每日 08:40):
   - 汇总全部已平仓交易:总览 + 按维度分组(反转类型/周期桶/方向/时段/1H结构/动量/持有时间);
   - 附最近 15 笔明细(理由 + 特征 + 盈亏);
   - 附"已证伪"清单(之前失败过的调整方向,不许重复提)。
3. **AI 提案**:由复盘 AI 输出结构化 JSON —— 分析 + ≤3 条变更,每条必须引用**具体统计数字**作为依据。
4. **程序护栏校验**(硬):
   - 只允许两类变更:**经验条目**(写入提示词自学习区)与**白名单参数**(带范围钳制);
   - 白名单:`momentum_exit_floor` / `time_stop_hours` / `max_short_positions` / `hot_pool_size` / `scan_open_every`;
   - **不可动的用户偏好**(提了也会被拒):止盈目标 2~3%、止损 1.5~5%、盈亏比下限(不许提 RR)、
     入场方式(反转后顺势,不许引入回踩/追中段)、空单对称;
   - 单次 ≤3 条;规则 ≤20 条、每条 ≤200 字;参数值必须在范围内,与现值相同则跳过。
5. **应用与版本**:变更前保存**快照**(规则 + 参数),写入 `tuning_log.json`;Telegram 通知每笔变更。
6. **自动回滚**:变更后累计 ≥10 笔平仓后,与变更前基线比较平均盈亏 —— **变差即自动回滚**,
   并记入"已证伪"(下一次提案时告诉 AI,防止重复踩坑)。

## 自我修改的两个入口

| 入口 | 文件 | 说明 |
|---|---|---|
| 经验条目 | `state/live/learned_rules.md` | `prompts.py` 把它追加到开仓/管仓系统提示词末尾,标注"与上文冲突时以本区为准" |
| 白名单参数 | `state/live/tuned_params.json` | 引擎启动时 `apply_tuned_overrides(cfg)` 覆盖 Config |

**代码与风控底线永不自动修改** —— 自我迭代的边界是"策略弹性",不是"安全约束"。

## 实测案例(2026-09-29 第一次自迭代, 基于 35 笔真实成交)

```
AI 分析: 亏损集中在 regular(16笔 胜率37.5% 累计-1.09)与 pre_market(9笔 44.4% -1.01)——
         两时段 25 笔 ≈ 全部亏损 -2.24; 持仓 6-24h 组胜率 54.5% 却平均为负 = 浮盈被拖回。

应用(经护栏校验后):
 - 规则: 常规盘/盘前开新仓须具备"放量突破确认", 否则跳过(依据: 该两时段构成全部亏损)
 - 规则: 浮盈单应在 1-6 小时内兑现(依据: 1-6h 组平均 +0.0334 vs 6-24h -0.0855)
 - 参数: AI 提议 min_rr 1.0→1.5 → **程序拒绝并作废**(与用户"止盈两个点"偏好冲突, 已记入已证伪)
```

## 运维

```bash
# 查看当前自学习经验
cat state/live/learned_rules.md
# 查看参数覆盖
cat state/live/tuned_params.json
# 查看版本历史与回滚记录
cat state/live/tuning_log.json
# 手动复盘(dry-run 只看提案不应用)
.venv/bin/python -m supermarket.self_tune --dry-run
# 定时器(已安装)
systemctl list-timers supermarket-selftune.timer
```
