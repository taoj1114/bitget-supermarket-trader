# 财报后漂移(PEAD)验证 — 结论: 不接入

数据源: Nasdaq 财报日历(免费, 含 EPS 惊喜%)+ 个股日线(Bitget 池内 / Yahoo 5 年)
方法: 财报日之后 fwd1/3/5 收益的均值与胜率, 与基准对比。

## 一、90/120 天(池内 211 只, Bitget 日线)

| 指标 | 值 |
|---|---|
| 样本 | 164~166 个财报事件 |
| fwd1 | +0.75% / 胜率 53.7% |
| fwd3 | +1.88% / 胜率 59.8% |
| fwd5 | **+2.87% / 胜率 61.0%** |
| 非财报期基准(池内) | -0.36% / 胜率 45.6% |

表面上很显著(胜率差 15.4pct)→ 但这是**单一样本期**,需大样本复核。

## 二、5 年大样本(2809 事件, Yahoo 日线 + Nasdaq 历史日历)— 证伪

| 指标 | 值 |
|---|---|
| fwd1 | +0.67% / 胜率 49.0% |
| fwd3 | +1.13% / 胜率 50.6% |
| fwd5 | +1.28% / 胜率 **50.6%** |
| fwd5 超额(vs SPY) | +0.83% / 胜率 48.8% |
| 基准 SPY fwd5 | +0.25% / 胜率 **58.7%** |

## 三、结论(不接入的理由)

1. 90 天样本的高胜率(61.0%)是**小样本假象**;5 年 2809 事件胜率仅 **50.6%(≈随机)**
2. 财报股 fwd5 胜率(50.6%)**低于大盘自身**(58.7%)→ 无"高胜率"优势
3. 收益为**右偏分布**(少数大涨拉动均值 +1.28%)→ 与超市"有浮盈就卖"的**高胜率小赚模式不匹配**
4. 按盈利惊喜分档**无区分度**(90 天: 超预期>5% → 57.9%, 低于预期<-5% → 63.3%)
5. **数据源不稳定**: Nasdaq 日历在数百次请求后开始返回 403(限流), 不适合作为实时数据源

脚本留档: `research/pead_eval.py`(支持 `python research/pead_eval.py <天数>`)。

## 附: 本轮"小样本 → 大样本"对照(方法论价值)

| 检验 | 小样本 | 大样本 | 结果 |
|---|---|---|---|
| PEAD fwd5 胜率 | 61.0%(120天) | 50.6%(5年/2809事件) | 证伪 |
| BTC 涨>3% 后胜率 | 37.0%(90天) | 56.8%(5年/1254天) | 证伪 |
| VIX<15 胜率 | 37.3%(2年/59样本) | 60.9%(5年/271样本) | 证伪 |

→ 三次都是"小样本看似有信号, 大样本回归平庸"。**候选信号必须先过大样本 + 多时段复核才能接入。**
