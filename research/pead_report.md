# 财报后漂移(PEAD)验证

样本: 164 个财报事件(池内公司)
- fwd1: n=164, 均值 +0.75%, 胜率 53.7%
- fwd3: n=164, 均值 +1.88%, 胜率 59.8%
- fwd5: n=164, 均值 +2.87%, 胜率 61.0%

基准(非财报期): fwd5 均值 -0.36%, 胜率 45.6%
## 5 年大样本验证(2026-09-16, 2809 事件) — 证伪

| 指标 | 值 |
|---|---|
| fwd1 | +0.67% / 胜率 49.0% |
| fwd3 | +1.13% / 胜率 50.6% |
| fwd5 | +1.28% / 胜率 **50.6%** |
| fwd5 超额(vs SPY) | +0.83% / 胜率 48.8% |
| 基准 SPY fwd5 | +0.25% / 胜率 **58.7%** |

**结论: 不接入。**
1. 90 天样本的高胜率(60.2%)是小样本假象; 5 年 2809 事件胜率仅 50.6%(≈随机)
2. 财报股 fwd5 胜率(50.6%)**低于大盘自身**(58.7%) → 无"高胜率"优势
3. 收益为右偏分布(少数大涨拉动均值) → 与超市"有盈利就卖"的高胜率小赚模式**不匹配**
4. 按惊喜分档无区分度(超预期/低于预期相近)

数据源(Nasdaq 免费日历 + Yahoo 日线)保留在研究脚本中备用。
